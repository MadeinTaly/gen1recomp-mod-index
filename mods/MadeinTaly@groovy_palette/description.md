Thirty more entries on the game's **COLORS** row, and eight new borders for
every text box and menu.

**The palettes** come in two packs. **RETRO** reconstructs another machine's
hardware — Amiga Workbench, C64, Virtual Boy, amber terminal, Spectrum, CGA,
Game Boy Pocket, Game Boy Light, Apple II, phosphor green, plasma orange.
**COLOUR** is eighteen ideas the Game Boy never had: rainbow, fuchsia,
vaporwave, sunset, ocean, forest, lava, ice, candy, neon, toxic, sepia,
noir, cherry, midnight, gold, mint, grape. They join the engine's own list
rather than replacing it, so the vanilla seven keep their positions and a
save pointing at SGB still lands on SGB.

**Previewing them.** Press **A** on `OPTION → COLORS` and the menu lifts off
the game: the palette's name over the running world, left and right to walk
the list, A to keep, B to put back the one you arrived with. The same
browser opens mid-game from `START → PALETTE` and hotkey `2`. Choosing a
colour from a menu covering the game is choosing blind — the browser exists
so you never have to.

**Riding ADVANCED.** The engine's ADVANCED mode resolves a real colour per
tile and keeps eight background palettes live at once — eighteen colours on
screen where a four-shade palette has four. Rather than switching that off,
each palette's four rungs are read as a curve indexed by luminance, so
ADVANCED's variety survives inside the palette's own hue family. `USE
ADVANCED` is settable to `TINT` (pull toward the palette), `FULL` (go all
the way onto the ramp), or `OFF` (the older four-shade behaviour). Packs
without the pokered-gbc engine fall back to `OFF` by themselves.

**The frames.** THIN, DOUBLE, TRIPLE, THICK, WIDE, DASH, BEADS and TRACK,
plus GAME BOY for the engine's own. A border in this engine is six font
glyphs; this ships its own glyph page generated by `tools/make_frames.py`
from rules written out in that file — every pixel authored there, nothing
extracted from a ROM.

| Option | Values | Takes effect |
| --- | --- | --- |
| `FRAME` | `GAME BOY` + eight | immediately |
| `USE ADVANCED` | `TINT` / `FULL` / `OFF` | immediately |
| `PREVIEW` | on / off | next launch |
| `PACKS` | `ALL` / `RETRO` / `COLOUR` | next launch |

`FRAME` and `USE ADVANCED` are read every time they are used, so you can
watch `FRAME` redraw the very menu you are choosing it in. `PREVIEW` and
`PACKS` rebuild the COLORS list at load time.

**What it does not do.** Four shades is still four shades — these recolour
the ramp, they do not add colours to a scene. Disable the mod with one of
its palettes selected and the game falls back to SGB; you lose the palette,
never the save.

Lua source and original artwork only: no ROM, no ROM-derived data and no
game assets.
